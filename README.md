# GW makelaars: WordPress proof of concept

Thema `gw-makelaars` en plugin `yc-realworks` (voorbeelddata, geen Realworks-token), met Polylang voor NL/EN.

Open in de browser (vervang USER/REPO, de repo moet publiek zijn):

https://playground.wordpress.net/?blueprint-url=https://raw.githubusercontent.com/USER/REPO/main/blueprint.json

De site draait volledig in de browser en begint bij elke keer laden opnieuw. Inloggen gaat vanzelf.
